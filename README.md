# 📚 Paper Haven

**Paper Haven** is an online library management platform where users can explore books, borrow their favorite books, and manage their borrowed collections.

🌐 **Live Website:** [Visit Paper Haven](YOUR_LIVE_SITE_URL)

## ✨ Key Features

- 📖 **Browse Books:** Explore a collection of books with detailed information.
- 🔍 **All Books:** View available books and discover your next favorite read.
- ➕ **Add Books:** Logged-in users can add new books to the library.
- 📚 **Borrow Books:** Borrow books easily with an automatic 14-day return date.
- 🔄 **Return Books:** Return borrowed books and automatically update available copies.
- 👤 **User Authentication:** Secure sign-up, sign-in, and profile management.
- 📦 **Stock Management:** Track available copies and prevent borrowing when books are out of stock.
- 📋 **My Books:** Manage books added by your account.
- 📚 **My Borrows:** View and manage your borrowed books.

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd paper-haven
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
